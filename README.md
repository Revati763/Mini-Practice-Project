# Mini-Practice-Project
A kid-friendly, interactive percentage calculator built with HTML, CSS, and JavaScript. Users enter their name and marks (out of 100), choose a Boy 👦 or Girl 👧 color theme, and get an animated result showing their percentage, a star rating, an encouraging message, and a thank-you note.

# Issue resolved

No frontend existed — the original was a console-only Java program (Scanner-based input/output). Now it has a full browser-based UI.
No personalization — added a Name field so the result greets the user by name.
One-size-fits-all design — added Boy/Girl theme toggle with distinct color schemes (blue/rocket vs pink/unicorn) instead of a single fixed look.
Not engaging for kids — added emojis, star ratings, encouraging messages, and animated background/gradient transitions.
No input validation — added a friendly error message if marks are outside 0–100 (the Java version would've just crashed or given a wrong result on invalid input).
Missing "thank you" message — added it as a styled note that appears after the result, per your original request.
